# 📱 Mobile Sales Dashboard (Power BI)

## 📌 Project Overview
Yeh Power BI dashboard mobile sales, customer ratings, payment methods, aur regional trends ko analyze karne ke liye banaya gaya hai. Iska main goal sales patterns ko samajhna aur business metrics ko visualization ke through clear tarike se show karna hai.

---

## 📊 Key Insights & Highlights
- **Total Sales & Revenue:** Overall sales performance aur month-on-month trend.
- **Top Mobile Models & Brands:** Sabse zyada bikne wale mobile models aur brand-wise sales analysis.
- **Payment Methods:** Customer preference (UPI, Credit Card, Debit Card, Cash, etc.) ka break-up.
- **Geographic Sales:** City-wise sales distribution (Delhi, Mumbai, Kolkata, Patna, etc.).
- **Customer Ratings:** Product satisfaction aur feedback level ka trend.

---

## 🛠️ Tools & Technologies Used
- **Power BI Desktop:** Visualizations aur interactive dashboard design ke liye.
- **DAX (Data Analysis Expressions):** Key measures aur metrics calculate karne ke liye.
- **Power Query:** Data cleaning aur transformation ke liye.
